# Skillset

Источник актуальных версий личных скиллов.

Первый снимок: 41 локальный скилл из `~/.agents/skills` и `~/.codex/skills`,
со всеми рабочими ресурсами. Кеши и файлы macOS исключены.

История первого коммита сохраняет исходное поведение. Происхождение и хеши
файлов зафиксированы в `sources.lock.json`. Встроенные скиллы и содержимое
плагинов остаются под управлением соответствующих приложений.

Локальные копии пока не заменены.
