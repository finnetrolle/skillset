# Skillset

Личный набор из **27 скиллов** для разработки, архитектуры, работы с задачами
и подготовки отчётов. Скилл - это инструкция для AI-агента: она объясняет,
как выполнять конкретную работу и какой результат получить.

Здесь хранятся актуальные версии скиллов. Их можно редактировать, сохранять
на GitHub и по команде переносить в папку, из которой агент их использует.

**[Все скиллы: зачем нужны и как работают](docs/skills.md)**

## Как это устроено

- `skills/` - инструкции и ресурсы каждого скилла.
- GitHub - история изменений и сохранённая версия набора.
- `~/.agents/skills` - установленные копии на этой машине.

Редактирование файлов и push обновляют репозиторий. Установленные копии
обновляются только командой `make install`.

## Установка

Нужны Git, Python 3.12+ и Make на macOS или Linux.

```sh
git clone https://github.com/finnetrolle/skillset.git
cd skillset
make setup
make check
make install
```

По умолчанию скиллы копируются в `~/.agents/skills`, которую использует Codex
на основной машине. Для другой папки укажи `TARGET`:

```sh
make install TARGET="$HOME/.codex/skills"
```

Выбери одну папку установки, чтобы несколько копий одного скилла не перекрывали
друг друга. Существующие ссылки Claude Code на общую папку продолжают работать;
их первоначальная настройка выполняется отдельно.

## Как пользоваться скиллами

Выбери скилл в [списке](docs/skills.md) и назови его агенту вместе с задачей.
Например:

```text
Используй grill-me, чтобы уточнить требования к регистрации пользователей.
Используй archify, чтобы показать устройство этого сервиса.
Используй diagnosing-bugs, чтобы найти причину нестабильного теста.
```

Для реализации готовой задачи `implement` вызывается явно:
`$implement <ID задачи>`. Он читает существующую задачу и выполняет её
по согласованным требованиям.

## Основные команды

Выполняй команды из папки репозитория.

| Команда | Что делает |
|---|---|
| `make list` | Показывает установляемый набор. |
| `make diff` | Показывает отличия от установленных копий. |
| `make install` | Устанавливает или обновляет весь набор. |
| `make install SKILL=tdd` | Обновляет один скилл вместе с его зависимостями. |
| `make rollback` | Откатывает последнюю установку. |
| `make upstream-check` | Проверяет, появились ли обновления у первоисточников. |
| `make upstream-diff SKILL=tdd` | Показывает изменения первоисточника для сравнения с локальной версией. |

Чтобы получить новую версию с GitHub и установить её:

```sh
git pull
make diff
make install
```

Если установленную копию меняли вручную, менеджер остановится перед её
заменой. Перенеси нужные правки в репозиторий и затем повтори установку.
Резервные копии установок хранятся в `<папка установки>/.skillset/`.

## Как изменить или добавить скилл

1. Отредактируй `skills/<имя>/SKILL.md` и нужные файлы рядом с ним.
2. Выполни `make check test`.
3. Сохрани изменения коммитом и отправь на GitHub.
4. Выполни `make install SKILL=<имя>`, когда захочешь обновить установленную копию.

Новый скилл также нужно зарегистрировать в `sources.lock.json`, чтобы
менеджер видел его файлы и зависимости. Правила работы с конкретным проектом
задаются в его `AGENTS.md` или `CLAUDE.md`.
