# Шкала фактчекинга

Используй эту шкалу для классификации тезисов, выбора доказательств и вынесения вердикта. Не оценивай универсальную истинность там, где исходный текст задаёт локальное правило воркшопа.

## 1. Тип тезиса

| Тип | Что сюда относится | Как проверять |
|---|---|---|
| Внешний факт | Наблюдаемое утверждение о мире, технологии, практике или результате | Прямые авторитетные источники |
| Продуктовый / версионный факт | Возможности, интерфейс, лимиты, команды, настройки конкретного продукта | Документация, release notes или код соответствующей версии; указать дату |
| Причинный / прогностический | «X приводит к Y», «скорее всего произойдёт Y», сравнение эффективности | Исследования или воспроизводимый эксперимент; не подменять корреляцией |
| Термин / классификация | Определение, название метода, типология | Первоисточник термина или несколько авторитетных употреблений; отметить отсутствие консенсуса |
| Рекомендация / эвристика | Совет, предпочтительный процесс, мера предосторожности | Не объявлять истинным или ложным; проверить фактическое обоснование и область применимости |
| Локальное правило / намерение | Формат конкретного воркшопа, договорённость команды, план демонстрации | Внешний фактчекинг не нужен; сверить с исходными артефактами при наличии |
| Внутренний факт | Утверждение о закрытом продукте, компании или процессе | Внутренний первичный документ либо демонстрация; без доступа — запросить подтверждение |
| Иллюстрация / метафора | Аналогия, риторический пример, переход | Обычно не включать; проверять только содержательный вывод, который ею обосновывают |

Если предложение содержит несколько типов, раздели его на отдельные тезисы.

## 2. Вердикт о достоверности

| Вердикт | Когда применять |
|---|---|
| ✅ Подтверждён | Точная формулировка прямо следует из качественных и актуальных доказательств |
| 🟡 Частично подтверждён | Ядро верно, но формулировка шире доказательств, теряет условие, смешивает верную и неверную части либо требует версионной оговорки |
| ❌ Опровергнут | Качественное доказательство прямо противоречит тезису или демонстрирует его фактическую ошибочность |
| ⚪ Недостаточно данных | Доказательств недостаточно, они косвенны, недоступны или между ними нельзя разрешить противоречие |
| 🔵 Не фактологический | Это рекомендация, локальное правило, намерение, ценностное суждение или метафора; универсальный вердикт «верно/неверно» неприменим |

Не используй `Подтверждён` для тезиса, который удалось подтвердить только после существенного переформулирования. В таком случае исходный тезис получает `Частично подтверждён`, а точная версия идёт в рекомендацию.

## 3. Уверенность

Уверенность описывает качество доказательной базы, а не силу формулировки.

- **Высокая** — прямой первичный источник нужной версии либо несколько согласующихся качественных источников.
- **Средняя** — один хороший источник, ограниченная переносимость, частичная косвенность или несущественное расхождение источников.
- **Низкая** — слабая доступность данных, существенная косвенность, спорная терминология или неразрешённый конфликт источников.
- **Неприменимо** — тезис не фактологический и не содержит проверяемого обоснования.

## 4. Отношение источника к тезису

Для каждого использованного материала зафиксируй одну роль:

- **подтверждает** — прямо поддерживает точную формулировку;
- **опровергает** — прямо ей противоречит;
- **ограничивает** — подтверждает лишь при условиях или показывает исключения;
- **контекст** — помогает понять термин, но сам по себе ничего не доказывает.

Не помещай источник, дающий только контекст, в доказательную колонку без пояснения.

## 5. Проверка атомарности

Перед исследованием задай четыре вопроса:

1. Может ли одна часть тезиса быть верной, а другая неверной?
2. Нужны ли для частей разные типы источников?
3. Содержит ли фраза одновременно правило и объяснение его пользы?
4. Меняется ли вердикт при удалении слов `всегда`, `обычно`, `может`, `для новичков`, `в этой версии`?

Любой ответ `да` — основание разделить или точнее зафиксировать тезис.

## 6. Рекомендации по исправлению

Предлагай минимальную правку, устраняющую выявленную проблему. Предпочитай:

- заменить абсолютное утверждение условным;
- назвать версию, дату или область применимости;
- отделить установленный факт от методической рекомендации;
- сослаться на доступный пользователю первичный источник;
- признать рабочую гипотезу и предложить измеримый эксперимент;
- удалить причинное объяснение, если доказано только совместное наблюдение.
