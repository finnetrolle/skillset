# Проверка текущего набора

## Упаковка и документация

Текущий набор: **27 скиллов, 277 файлов**. Каталог источников, папки,
реестр согласований и статистика описывают одни и те же пакеты.

```sh
make check test catalog-check
```

Проверка упаковки проходит YAML metadata, имена, файлы, UI icons, зависимости
и связанные Markdown references. Каталог генерируется из текущего manifest
и агрегированной статистики. Набор содержит 23 согласованных пакета без
дополнительных доработок и четыре с уточнёнными инструкциями:
`grill-me`, `epic-to-issues`, `analyze-via-sonar`, `cavecrew`.

Проверки выполняются локально. GitHub Actions отключены.

## Тесты менеджера

22 теста используют публичный CLI, временные targets и синтетические журналы.
Проверяются:

- доставка ресурсов, executable bit и зависимых пакетов;
- повторная установка без изменений и точный backup/rollback;
- ручные правки, ранний отказ и сохранение других пакетов при миграции;
- dry-run без создания target, ошибки аргументов и metadata;
- восстановление после прерванного install/rollback и отказ при повреждённом backup;
- защита aliases и сохранение вытесняемых правок при согласованном overwrite;
- upstream diff на локальном Git fixture с сохранением pin и адаптации;
- учёт .system, режима --all, дедупликация и атрибуция usage в Codex/Claude logs.

Тесты не используют реальные домашние папки скиллов или пользовательские журналы.

## Поведенческие проверки скиллов

Проверки 07.10.2026 использовали изолированные fixtures и фиксировали
наблюдаемые действия. Они подтверждают приведённые сценарии, а не все
возможные режимы каждого скилла.

| Скилл | Сценарий и результат | Граница проверки |
|---|---|---|
| grill-me | При согласованном CSV import принятые решения сохранены; задан вопрос о partial/atomic import. | Проверен первый ход ранней адаптации. Полное интервью и весь цикл счётчика прогресса отдельно не прогонялись. |
| domain-modeling | При существующем CONTEXT.md использован канонический customer; glossary/ADR не созданы без разрешения. | Совет по модели в изолированном проекте. |
| writing-for-agents | Сокращены инструкции release skill с сохранением explicit-only policy и approval. | Публикация и изменение policy не выполнялись; runtime discovery хостов отдельно не проверялся. |
| issue-dialogue | Согласованный /health header change записан в локальную issue с evidence matrix без нового интервью. | Код сервиса не менялся; HTTP fixture не стартовал из-за запрета bind localhost. |
| diagnosing-bugs | CSV CLI воспроизвёл total "1020" вместо 30; после исправления subprocess test подтвердил числовой total и сохранение records. | Реально выполнены команды изолированного CLI fixture. |
| epic-to-issues | Draft исключён из frontier; expand блокирует три миграции, contract ждёт их все. Проверены ссылки, mirrors и DAG. | Планирование и публикация в Markdown fixture; service acceptance suite не запускался. |
| analyze-via-sonar | Планы сохранили настройки Gradle/Maven. При Python upload 503 отвергнуты устаревшие metadata и сохранён прежний реестр. | Dry-run на трёх fixtures; build, scanner, Docker, живой сервер и API не запускались. |
| cavecrew | Исследование нашло определение и два вызова; inline review выявило limit=0; три связанных файла получили общий scope; CLI builder прошёл regression RED и три GREEN tests. | Схемы инструментов были fixture inputs; реальный Claude runtime и вложенная делегация не запускались. |

В `epic-to-issues` отдельно проверено, что неизвестный исходный результат
остаётся pending до его измерения: порядок входных данных не используется
как выдуманный regression oracle. Прогон разрешал атомарную смену протокола
после согласования, с сохранением обязательных условий верификации.

Через публичный CLI во временных targets проверены:

| Пакеты | Файлы | Результат |
|---|---:|---|
| epic-to-issues, issue-dialogue, domain-modeling | 12 | Точное содержимое и executable bit, повторный install unchanged, rollback успешен. |
| analyze-via-sonar | 3 | Точное содержимое и executable bit, повторный install unchanged, rollback восстановил пустой target. |

Рабочая установка 07.10.2026 доставила 27 общих пакетов и 277 файлов из
коммита `0140ffe` в `~/.agents/skills`. Transaction:
`20261007T134925-914e67b1`. Тогда все пакеты совпали по содержимому и executable
bit, повторный install вернул unchanged, pending transactions отсутствовали.

Claude использует 26 ссылок на общий набор и самостоятельный `tdd`.
Последующие изменения документации в репозитории доставляются по явной
команде install, как и остальные изменения пакетов.

подтверждает работоспособность всех внешних интеграций.
