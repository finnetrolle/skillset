# Текущие скиллы и Matt Pocock

Сравнение относится к текущему набору из 27 скиллов и закреплённой версии
[mattpocock/skills](https://github.com/mattpocock/skills/tree/dd400c3ad65e57c06f05e832e0aac92c7992f34d).
Сопоставления для повторной сверки находятся в
[sources.lock.json](../sources.lock.json). Решения пользователя и согласованные
доработки записаны в [реестре](../data/skill-audit.json).
Закреплённая версия не означает автоматическую синхронизацию с HEAD.

проверки по риску и проекту.

## Особенности epic-to-issues

Пакет `to-tickets` дополнительно сверялся 07.10.2026 с
[коммитом f3fc563](https://github.com/mattpocock/skills/tree/f3fc5632f401156837ee3872f14fe33ccf1024ea);
изменений относительно pin не обнаружено.
Локальный контракт включает четыре согласованных уточнения:

- Draft и Blocked исключаются из runnable frontier; готовые задачи ждут
  завершения блокирующих зависимостей.
- Issue-dialogue задаёт требования к готовности и планируемым доказательствам
  приёмки. Структурные критерии получают подходящие способы проверки.
- Expand, migrate и contract имеют отдельные зависимости и проверки.
  Интеграционная ветка требует согласования и сохраняет условия завершения.
- Перед публикацией проверяются размер задач, блокировки и необходимость
  объединения или разделения. Предложения получают реальные ссылки
  в порядке зависимостей.

План проверки сохраняется как план, пока команды фактически не выполнены.
Зависимость от issue-dialogue обеспечивает доставку этого общего контракта.

## Как обновлять сравнение

`make upstream-check` проверяет HEAD зарегистрированных источников.
`make upstream-diff SKILL=tdd` показывает изменения относительно pin и
локальную адаптацию SKILL.md. `--full` возвращает полный diff;
дополнительные ресурсы сравниваются отдельно.

Для OpenAI источник выбирается явно:

```sh
.venv/bin/python scripts/manage.py upstream-diff --source openai --skill security-best-practices
```

После принятия полезных изменений обнови pin и происхождение, проверь поведение
и установи версию по отдельной команде. Сохраняй локальный контракт при
переносе upstream-изменений.
